# Resource Quality Checklist

Use this checklist before marking a resource as verified.

- [ ] Canonical HTTPS URL opens successfully
- [ ] Resource name matches the destination
- [ ] Description is factual and matches the current offering
- [ ] Category and type are appropriate
- [ ] Language claims are supported by the resource
- [ ] Audience tags are reasonable
- [ ] Duplicate URL/title checked against existing datasets
- [ ] `official` marked only when the destination is the official source
- [ ] `free` marked only when access/use is actually free
- [ ] `verified` marked only after a human maintainer has reviewed it
- [ ] `addedAt` recorded for new resources
- [ ] `updatedAt` changed whenever the record is materially reviewed or corrected

## Review outcome

**Verified:** all applicable checks passed.

**Needs review:** one or more claims require manual confirmation.

**Needs correction:** metadata or URL is incomplete/incorrect.

**Rejected:** resource is unsuitable, inaccessible, duplicate, or cannot be reliably verified.
